Task 1: PDF file support
Narration language: English

Scene 1: Task 1 adds selectable-text PDF support to the starter RAG pipeline. The purpose is to answer from course documents while preserving the evidence page for review.

Scene 2: The implementation reads each PDF page with pypdf, records the filename and one-based page number, splits text into chunks of 1,000 characters with 200 characters of overlap, then embeds and stores the chunks in Chroma.

Scene 3: In the verified assignment-PDF demonstration, the system indexed 41 chunks. It answered that the project has seven main tasks and returned source references to the supplied PDF pages.

Scene 4: This test covers PDFs with selectable text. A scanned, image-only PDF still needs OCR; that limitation is documented so the output is not mistaken for full document-image support.
