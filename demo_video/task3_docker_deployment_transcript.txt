Task 3: Docker deployment
Narration language: English

Scene 1: Task 3 packages the RAG application so its Python environment and deployment steps can be reproduced with Docker Compose.

Scene 2: The image uses a digest-pinned Python base and locked dependencies. Compose mounts the CS handbook read-only and saves Chroma data in a named volume that survives container replacement.

Scene 3: Ollama runs on the Mac host. Docker reaches it through the host gateway at port eleven thousand four hundred thirty-four, so model management stays outside the application image.

Scene 4: A fresh volume indexed fifty-seven handbook chunks. A later run reused that index, answered that CS 313 is the prerequisite for CS 311, and cited page eighteen.
